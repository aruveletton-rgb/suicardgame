## 原审计八项语义

1. 完整回合结束且仍持岁牌时开放有岁质疑。
2. 年牌必选弃牌超时保留步骤并暂停。
3. 年牌收集申报后按杠＞碰＞吃、同级方向距离裁决。
4. 望控制链支持合法岁牌和 +4 子链并恢复。
5. 令等即时牌在影响目标前开放左乐/规避响应。
6. +4 质疑窗口有真实服务端到期任务。
7. 到期产生后继窗口时继续统一调度。
8. 普通回合有 90 秒到期暂停路径。

上述语义已纳入 `backend/tests/acceptance/test_audit_semantics.py` 及 Agent 专属回归。正式夹具不再 monkeypatch 自动 READY。

## 主要实现

- 后端：统一 deadline 调度、持久暂停、继续/中止、旧任务隔离、头像与快照兼容。
- 规则：有岁交付/罚摸、高辈分规避、年竞争、望嵌套、左乐响应、黍输入原子性与 UNO/结束链。
- 对局 UI：桌面围桌、手机竖/横布局、可见上下文选牌、商店交换确认、响应条、暂停与结果。
- 产品 UI：自包含 UNO/牌背、角色裁切卡面、头像、昵称记忆、安全邀请二维码、5 席大厅、完整图鉴。
- QA：旧夹具真实 READY/5 人迁移、跨平台临时目录、当前 Chromium E2E、截图与 PID 采样。
