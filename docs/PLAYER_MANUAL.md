# 岁牌 UNO 玩家手册

本手册适用于当前版本的 `suicardgame`。游戏以经典 UNO 为基础，加入岁牌和坎诺特商店。所有牌局状态由服务端结算，屏幕上的高亮牌和可用按钮就是当前步骤允许的操作。

## 1. 开始游戏

### 创建或加入房间

1. 输入昵称并选择头像。
2. 点击“创建房间”，成为房主；或输入 6 位房间号，点击“加入房间”。
3. 房间支持 2–5 名玩家。
4. 房主可以在大厅点击“+”或“−”设置机器人数量。机器人会自动准备，并在成员列表中标记为“机器人”；真人和机器人可以混合对战。

### 大厅操作

- 点击“我已准备”或“取消准备”切换自己的准备状态。
- 房主必须等所有在座玩家在线且已准备，才能点击“开始牌局”。机器人默认在线且已准备。
- “复制”可以复制房间号；“复制邀请链接”可以分享公开邀请链接。邀请链接不包含登录会话或重连令牌。
- 点击“图鉴”查看通用规则和每张岁牌的详细说明。

## 2. 基本目标与牌组

- 每局 2–5 人，每位玩家起手 7 张牌。
- 目标是先把自己的手牌出完。
- 普通牌有红、黄、绿、蓝四种颜色；数字牌为 0–9，另有 Skip、Reverse、Draw Two。
- Wild 可以随时打出并选择颜色。
- Wild Draw Four 只有在手中没有当前颜色牌时才能打出。
- Wild Draw Four 打出后，下一位玩家直接摸 4 张并结束其等待，当前版本没有 `+4` 质疑窗口。
- `+2` 和 `+4` 不能互相叠加。
- 牌局中加入岁牌和场地牌；场地牌“坎诺特”不属于任何玩家的手牌。

## 3. 轮到自己时怎么操作

### 选择手牌

手牌区上方有三种选择用途：

- **主牌**：用于普通出牌、发动一张岁牌或单牌响应。
- **多选牌**：用于易牌、余牌等需要多张牌的操作。
- **支付牌**：用于商店交换等支付操作。

点击手牌即可按当前用途选择。后端允许的牌会高亮；响应步骤中不合法的牌不能点击。若提示“请选择高亮的牌”，请先选择高亮牌。

### 普通出牌

1. 选择一张主牌。
2. 普通牌必须匹配弃牌堆顶牌的颜色、数字或动作符号。
3. Wild 或 Wild Draw Four 需要先选择红、黄、绿、蓝之一。
4. 点击“确认出牌 / 发动”。

### 摸牌

- 在自己的回合点击“摸牌”。
- 手中存在可出的牌或可发动的主动岁牌时不能摸牌跳过回合。
- 如果手中没有任何可行动牌，系统会持续摸牌，直到摸到可出的牌；摸到后仍保留当前回合，请先把可出的牌打出。
- 牌库和弃牌堆都无法继续提供牌，且当前玩家没有合法出牌时，牌局会按手牌数结算。

### UNO

- 出牌后手中只剩 1 张时，应在出牌前勾选“随出牌宣告 UNO”。
- 若系统提示你必须宣告 UNO，点击“宣告 UNO”。
- 其他玩家在抓取窗口内看到你未宣告，可以点击“抓取 玩家名”；抓取成功后由后端执行罚牌。

## 4. 响应窗口

特殊效果发生时，桌面会出现“需要响应”面板。面板会显示来源、是否为必选操作、倒计时和规则提示。

1. 只有当前授权响应者能提交按钮，其他玩家会看到“等待授权响应者”。
2. 若操作需要选牌，先在手牌区选择主牌、多选牌或支付牌，再点击响应按钮。
3. 若操作需要颜色或目标，先在控制区选择颜色或玩家。
4. 响应提交后等待服务端结算；不要重复点击。

### 高辈分规避

当岁牌效果将影响自己时，如果响应面板提供“使用高辈分牌规避”，可以选择一张比来源岁牌辈分更高的岁牌作为响应。规避牌只用于本次规避，不会同时发动它自己的主动效果。

辈分从高到低为：

`重岳 > 望 > 令 > 黍 > 易 > 夕 > 余 > 左乐`

### 夕牌和左乐

- **夕牌**只能在被动步骤明确要求提供、展示或弃置一张牌时使用，不能在普通回合随意发动。
- **左乐牌**只能在岁牌效果尚未影响目标的响应窗口中使用。选择目标后，本次岁牌效果在本回合内对该目标无效，目标可以是自己。

## 5. 岁牌规则

### 望牌

当当前玩家没有任何合法普通牌可出时使用。选择该玩家后，望牌使用者可以控制其后续操作，并把自己的手牌也作为可用手牌参考。控制会持续到望牌使用者自己的回合开始。

### 余牌

1. 先支付红、黄、绿、蓝各一张牌。
2. 其他玩家依次弃置一张本轮尚未出现过颜色的牌，或选择放弃。
3. 有玩家放弃时，余牌使用者可以停止，或再次支付四色牌，从该玩家处重新开始。

### 易牌

选择两张数字牌，点数之和必须为 8。弃置后其他每位玩家摸 1 张；同一回合可以重复发动。

### 黍牌

当某种颜色的手牌数量不少于其他玩家人数时，可以选择该颜色。该颜色的全部手牌会尽量平均分给其他玩家；有余牌时交给当前手牌最少的玩家之一，并列时由使用者选择。

### 重岳牌

所有玩家按顺序展示红、黄、绿、蓝四种颜色的牌。缺少颜色的玩家持续摸牌并展示，直到颜色齐全。展示阶段结束后，其他玩家可以质疑重岳牌使用者，系统按质疑结果结算。

### 令牌

发动时记录全场单人最高手牌数。所有低于该数量的玩家依次摸牌补齐；目标数量在发动时冻结，中途增加的手牌不会抬高目标。

## 6. 坎诺特商店

商店位于牌桌中央，开局会有 8 张商品牌。

### 购买商品

1. 点击“展开商品”。
2. 点击想购买的商品。
3. 切换手牌用途为“支付牌”，再选择一张支付牌。
4. 点击“确认交换”。

有色商品要求支付牌匹配颜色或数字；无色商品可以用任意牌支付。Wild 和 Wild Draw Four 不会出现在商店中。每名玩家每回合最多购买一次。

### 刷新商品

在自己的回合点击“刷新”。每名玩家每回合最多刷新一次；刷新会把当前商品放回弃牌区域，再从牌堆补充商品。

## 7. 操作时限、暂停与重连

- 普通回合：90 秒。
- 必须选牌、选色、选目标或交牌：30 秒。
- 一般可选响应：15 秒。
- 质疑窗口：10 秒。

可选响应超时会按默认的放弃或跳过处理。普通回合和必选操作超时会暂停牌局，不会自动替你选牌、弃牌或推进。

暂停时：

- 房主点击“继续等待并重置时限”，保留原步骤并重新计时。
- 房主点击“结束本局”，本局中止，不按剩余手牌产生胜者。
- 其他玩家等待房主处理。

浏览器断线后重新打开游戏或使用原会话，系统会尝试恢复房间和自己的手牌。响应窗口、暂停状态和当前回合由服务端保存。

## 8. 结算与再来一局

- 玩家手牌出完并完成必要的岁牌效果结算后获胜。
- 如果牌库耗尽且当前玩家无法出牌，系统显示“牌库耗尽，按手牌数判胜”，按结算时手牌数判定胜者。
- 结算页显示所有玩家的剩余手牌数。
- 只有房主可以点击“再来一局”；点击后返回大厅，所有真人玩家需要重新准备，机器人会自动准备。

## 9. 常见提示

| 提示 | 处理方式 |
| --- | --- |
| 请选择高亮的牌 | 当前响应只能选择高亮牌，先点击手牌中的高亮牌。 |
| 这张牌当前不能打出 | 检查当前颜色、数字、动作符号和响应窗口。 |
| 请选择颜色 | 在控制区选择红、黄、绿或蓝。 |
| 请选择目标 | 在控制区选择合法玩家；有些牌允许选择自己。 |
| 当前不是你的回合 | 等待桌面顶部“当前”变为自己的昵称。 |
| 牌局已暂停 | 等待房主继续等待或结束本局。 |
| 响应窗口已关闭 | 倒计时已结束或其他玩家已完成结算，等待下一步状态同步。 |

## 10. 快速上手

第一次游戏可以按以下顺序练习：

1. 创建房间，添加 1–2 个机器人。
2. 准备并开始游戏。
3. 先练习匹配颜色或数字出牌、Wild 选色和“随出牌宣告 UNO”。
4. 没有可出牌时点击“摸牌”，观察系统持续摸到可出牌。
5. 遇到响应面板时，先看规则提示，再选择高亮牌和响应按钮。
6. 点击“图鉴”查看岁牌原图和完整步骤。
