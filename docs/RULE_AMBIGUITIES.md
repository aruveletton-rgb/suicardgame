# 规则歧义记录

更新日期：2026-09-29。

当前第一阶段未发现必须打断 UI 和容量改版的阻塞性歧义。以下时间协议已由本轮用户决定，不再沿用旧默认值：

- 普通回合：90 秒。
- 颜色、目标、多选弃牌或岁牌交付：30 秒。
- 左乐、辈分规避和吃碰杠：15 秒。
- Wild Draw Four 质疑、有岁和其他可选质疑：10 秒。
- 必选步骤超时：服务端暂停并保留原步骤；房主继续等待或中止本局。

以下三项没有新的权威用户裁决，仍是当前实现为保证回归一致性所采用的实施假设，不应解读为本轮新增规则裁决：

- 多人同时“有岁！”：当前实现按出牌方向距离选择最近的有效质疑者，后续质疑者关闭且不消耗。
- 末牌嵌套结算：当前实现先完成关联效果、质疑、罚摸和交付，再判断来源是否仍为空手胜利。
- 同时“看到”排序：当前实现按事件来源之后的出牌方向距离串行结算。

来源与影响：这些假设沿用既有引擎和第二轮/第三轮回归证据；它们影响多人有岁竞争、末牌结束时机和同时触发的顺序，但本轮不修改引擎行为。若获得新的规则材料，应单独记录来源并重新评估对应测试。

若后续实现卡面细节时出现提示词和卡面原文不可调和的冲突，将追加记录原文、冲突点、候选解释、影响范围和推荐默认值。
