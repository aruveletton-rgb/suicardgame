# 规则歧义记录

当前第一阶段未发现必须打断 UI 和容量改版的阻塞性歧义。以下时间协议已由本轮用户决定，不再沿用旧默认值：

- 普通回合：90 秒。
- 颜色、目标、多选弃牌或岁牌交付：30 秒。
- 左乐、辈分规避和吃碰杠：15 秒。
- Wild Draw Four 质疑、有岁和其他可选质疑：10 秒。
- 离线重连宽限：暂定 45 秒。

仍待集中裁决的行为歧义：

- 多名玩家同时“有岁！”时的竞争顺序。
- 最后一张牌引发嵌套效果时的胜负结算顺序。
- 卡面“看到”同时发生时的事件排序。
- 必选 Prompt 超时后的显式暂停状态迁移；当前旧 resolver 的默认动作不能替代暂停协议。

若后续实现卡面细节时出现提示词和卡面原文不可调和的冲突，将追加记录原文、冲突点、候选解释、影响范围和推荐默认值。
