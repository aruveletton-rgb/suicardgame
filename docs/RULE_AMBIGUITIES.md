# 规则歧义记录

更新日期：2026-09-28。

当前第一阶段未发现必须打断 UI 和容量改版的阻塞性歧义。以下时间协议已由本轮用户决定，不再沿用旧默认值：

- 普通回合：90 秒。
- 颜色、目标、多选弃牌或岁牌交付：30 秒。
- 左乐、辈分规避和吃碰杠：15 秒。
- Wild Draw Four 质疑、有岁和其他可选质疑：10 秒。
- 必选步骤超时：服务端暂停并保留原步骤；房主继续等待或中止本局。

- 多名玩家同时“有岁！”时的竞争顺序。

- 卡面“看到”同时发生时的事件排序。
