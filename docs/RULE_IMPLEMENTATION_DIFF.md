## 当前实现的竞争与结算顺序（实施假设）

### 1. 多人同时有岁质疑

- 当前实现（实施假设，非新增用户裁决）：按被质疑者之后的出牌方向距离，只接受最近的一名有效质疑者；其他人无消耗关闭。
- 证据：`backend/tests/agent_rules/test_rule_windows.py` 的竞争回归。

### 2. 最后一张牌触发连锁后的胜负

- 当前实现（实施假设，非新增用户裁决）：等该牌及全部关联响应、罚摸、交付结束后再判胜；若期间重新获得手牌则不胜。被动摸牌触发的效果不因空手自动成为胜利候选。
- 证据：Ji、余、夕湘、王嵌套及福州被动触发回归。

### 3. 同时“看到”事件排序

- 当前实现（实施假设，非新增用户裁决）：按事件来源之后的出牌方向距离逐个完整结算。
- 证据：`test_seen_events_queue_and_resolve_by_direction_distance`。

以上三项已有实现和回归，但没有新的权威用户确认；本轮不修改引擎行为。获得新的规则材料后，应重新评估实现和对应测试。
