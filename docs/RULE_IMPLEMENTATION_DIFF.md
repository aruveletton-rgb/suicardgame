## 真正待用户裁决

### 1. 多人同时有岁质疑

- 建议：按被质疑者之后的出牌方向距离，只接受最近的一名有效质疑者；其他人无消耗关闭。
- 备选：允许所有质疑者依次结算。
- 影响：交牌/罚摸次数、并发响应幂等和窗口结束条件。

### 2. 最后一张牌触发连锁后的胜负

- 建议：等该牌及全部关联响应、罚摸、交付结束后再判胜；若期间重新获得手牌则不胜。
- 备选：手牌清零立即锁定胜者。
- 影响：望/黍/+4/有岁等父子效果和结果阶段时机。

### 3. 同时“看到”事件排序

- 建议：按事件来源之后的出牌方向距离逐个完整结算。
- 备选：固定座位号或批量同时入队。
- 影响：岁相/重岳等触发顺序、牌张守恒与后继窗口。

当前实现不会把上述三项伪装成已裁决：遇到无法安全确定的竞争会拒绝第二个冲突决定或保留明确状态，其余已决定规则继续运行。
