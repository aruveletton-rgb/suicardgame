# 第二轮规则实现差异

日期：2026-09-29。本文只记录本轮有岁语义修复及其与既有规则的关系；不把独立审计材料当作规则来源。

## 有岁窗口

- 公开窗口的“是否允许质疑”与私有“本次冻结的合格岁牌集合”分离。
- 来源玩家仍有牌时，完整回合及关联效果结束后统一开放 10 秒 `HAS_SUI_CHALLENGE`；公开 prompt 不携带持岁标志、合格 ID、数量或私有候选。
- 服务端在窗口创建时冻结合格集合。成功质疑转入被质疑者 30 秒必选自选交付；无合格岁牌的错误质疑进入真实失败路径，由质疑者摸四张，来源不交牌、不罚摸，罚摸新牌不倒算。
- 来源已经空手时继续跳过无意义终局窗口，交由现有胜负结算处理；本轮没有为了防泄露给空手终局增加等待。

## 保持不变的已确认规则

2–5 人、全员在线且 READY、杠＞碰＞吃、90/30/15/10 秒、必选超时暂停、可选超时放弃、重连/幂等/私有快照，以及有岁成功交一张并摸四张均沿用现有实现和回归。上一轮记录的多人质疑竞争、末牌嵌套胜负、同时“看到”排序在本轮未重新设计；若无新的权威来源，应继续视为实施假设而非本轮新增用户裁决。
