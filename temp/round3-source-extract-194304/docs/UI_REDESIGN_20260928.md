# UI 改版说明（2026-09-28）

## 已实现

- 首页与牌桌统一为墨黑/深灰战术终端底色，米白正文、朱红警示、金色局势信息和青绿色辅助色。
- `CardView` 对普通 UNO 牌使用前端 DOM/CSS 绘制。数字、Skip、Reverse、+2、Wild 和 +4 保留颜色、符号、四角识别元素，不再依赖 SVG 内的外部 JPG。
- 岁牌继续使用 `public/assets/cards/sui/` 原图，但以统一卡框、角色名和“岁”标识显示；规则正文在图鉴抽屉中结构化展示，原图不再承担微小卡面正文。
- 桌面布局保留玩家侧栏、中央牌堆、常驻商店和底部手牌；窄屏竖屏将对手状态置顶、商店折叠；短高度横屏压缩顶部和手牌，商店默认收起。
- 图鉴、商店展开/收起、响应提示和手牌选择均使用现有联机状态，不创建脱离 WebSocket 的演示状态。
- 大厅容量文案统一为 2–5 人；开始按钮在前端等待所有在座且在线玩家准备，后端仍做最终校验。

## 素材映射

14 张附件图片与 `frontend/public/assets/cards/sui/` SHA-256 一致。映射以 `frontend/src/data/cardManifest.json` 为准；原图入口保留在规则图鉴卡面中。普通牌的原 SVG 仍作为历史资源保留，但运行时不再由 `CardView` 加载。
